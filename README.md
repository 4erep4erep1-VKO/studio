# 🛠 Montazhka PRO v3.0

Комплексная CRM-система и Telegram-бот для управления производством наружной рекламы. Объединяет веб-панель для администраторов и мобильный интерфейс (через Telegram) для сотрудников: монтажников, печатников и дизайнеров.

## 🚀 Главные фишки

* **Умное распределение задач:** Разделение заказов на «Общие» (кто успел, тот забрал) и «Личные» (с моментальным push-уведомлением конкретному сотруднику).
* **Разделение по ролям:** Гибкая система допусков (Дизайн, Печать, Монтаж). Каждый видит только свою работу.
* **Глубокая интеграция с Telegram-группой:**
  * Создание заказов прямо из чата по хештегу `#заказ`.
  * Автоматическая пересылка фотоотчетов со сданных объектов в общую группу.
  * Утренняя сводка (будильник) по горящим дедлайнам каждый день ровно в 08:00.
* **Геймификация:** Встроенный рейтинг (Топ сотрудников по закрытым задачам) для мотивации команды.
* **Быстрая админка:** Вход по PIN-коду, загрузка фото через буфер обмена (Ctrl+V), массовые рассылки объявлений всему персоналу.

## 💻 Технологический стек

* **Frontend / Web Admin:** Next.js (React), Tailwind CSS, Lucide Icons.
* **Backend / Database:** Supabase (PostgreSQL, Storage, Realtime).
* **Telegram Bot:** Python 3, aiogram 3.x, FSM (Машина состояний).
* **Хостинг:** Vercel (Сайт) / Любой VPS или облако (Бот).

## 🗄 Структура Базы Данных (Supabase)

Проект использует две основные таблицы и одно хранилище (Storage):

1. **`profiles`** (Сотрудники)
   * ID, ФИО, PIN-код, Роль (admin/installer).
   * Допуски (`can_design`, `can_print`, `can_install`).
   * `telegram_chat_id` (для связи сайта с ботом сотрудника).

2. **`orders`** (Заказы)
   * Название, описание, дедлайн, отдел (`department`).
   * Статус (`new`, `in_progress`, `completed`).
   * Автор (`created_by`) и Исполнитель (`assigned_to`).
   * Фото (эскизы `image_urls` и финальный отчет `report_photo`).

3. **Storage Bucket:** `order-photos` (Папки `previews/` и `reports/`).
