# 🛠 Монтажка PRO — Система управления производством

Полноценная ERP-система для рекламно-производственной компании (дизайн, печать, монтаж). Связывает веб-админку (Канбан-доску) и Telegram-бота для сотрудников в единую экосистему через базу данных Supabase.

## 🚀 Основной функционал

### 1. Ролевая модель
- **👑 Администратор:** Полный доступ к веб-админке. Может создавать/удалять заказы, управлять сотрудниками (добавлять ПИН-коды, выдавать допуски), скачивать Excel-отчеты, делать рассылки и **принудительно назначать** заказы на сотрудников.
- **🎨 Дизайнер:** Доступ к веб-админке (только Канбан-доска и создание объектов) и кнопка создания заказа в Telegram-боте.
- **👷 Сотрудник (Печатник / Монтажник):** Работает только через Telegram-бота. Берет доступные задачи в работу, отчитывается о выполнении.

### 2. Веб-панель (Next.js)
- **Вход по ПИН-коду:** Быстрая авторизация без сложных паролей.
- **Канбан-доска:** Автоматическое распределение заказов по колонкам (🆕 Новые, ⏳ В работе, ✅ Готово).
- **Ручное назначение:** Администратор может нажать «Назначить» и передать зависший заказ конкретному сотруднику (ему придет пуш в ТГ).
- **Управление командой:** Настройка допусков (Дизайн, Печать, Монтаж) для каждого профиля.
- **Excel-отчеты:** Выгрузка завершенных объектов за выбранный период.
- **Глобальные объявления:** Рассылка сообщений от имени бота всем сотрудникам прямо из админки.

### 3. Telegram-бот (Python, aiogram) и Mini App
- **Раздельные клавиатуры:** У админов/дизайнеров есть кнопка «📝 Создать заказ», у работяг — только списки задач и профиль.
- **Telegram Web App:** Форма создания заказа открывается прямо внутри мессенджера и адаптируется под тему пользователя.
- **Уведомления:** Бот автоматически пишет в общую группу о новых заказах и присылает в личку уведомления о персональных назначениях.

### 4. ⚙️ Производственный конвейер (Магия передачи)
Уникальная логика для отдела печати:
Когда печатник завершает работу над баннером, у него есть два пути:
1. **«В офис»:** Заказ просто закрывается (клиент заберет сам).
2. **«На монтаж»:** Заказ автоматически меняет отдел на «Монтаж», сбрасывает исполнителя, возвращается в статус «Новый» и отправляет уведомление монтажникам в общую ТГ-группу, чтобы они забрали готовый баннер в работу.

## 🛠 Технологический стек

- **Frontend:** Next.js (React), Tailwind CSS, Lucide Icons, Canvas Confetti.
- **Backend/DB:** Supabase (PostgreSQL, Realtime subscriptions).
- **Telegram Bot:** Python 3, `aiogram` 3.x.
- **Export:** `xlsx` (для генерации Excel-отчетов на лету).

## 📂 Структура базы данных (Supabase)

### Таблица `profiles`
- `id` (uuid, PK)
- `full_name` (text)
- `pin_code` (text)
- `role` (text: 'admin', 'installer')
- `telegram_chat_id` (text, nullable)
- `can_design` (boolean)
- `can_print` (boolean)
- `can_install` (boolean)

### Таблица `orders`
- `id` (uuid, PK)
- `title` (text)
- `description` (text)
- `status` (text: 'new', 'in_progress', 'completed')
- `department` (text: 'print', 'installation')
- `deadline` (timestamp)
- `is_general` (boolean)
- `assigned_to` (uuid, FK to profiles)
- `created_by` (uuid, FK to profiles)
- `preview_url` (text, nullable)
- `report_photo` (text, nullable)

## ⚙️ Настройка и запуск

### 1. Переменные окружения веб-сайта (`.env.local`)
```env
NEXT_PUBLIC_SUPABASE_URL=твоя_ссылка_supabase
NEXT_PUBLIC_SUPABASE_ANON_KEY=твой_ключ_supabase
NEXT_PUBLIC_TELEGRAM_BOT_TOKEN=токен_твоего_бота
2. Настройка Telegram-бота (main.py или config.py)
Обязательно пропиши ID администраторов и дизайнеров в коде бота, чтобы у них появилась кнопка создания заказа:

Python
# Добавь сюда свой ID, ID директора и дизайнеров
ALLOWED_IDS = [123456789, 987654321] 
3. Деплой
Сайт: Рекомендуется деплой на Vercel (не забудь прописать Environment Variables в настройках проекта).

Бот: Рекомендуется запуск на любом облачном сервере (например, Wispbyte, Railway, Render) в режиме 24/7.

Сделано с кайфом для реального производства.
