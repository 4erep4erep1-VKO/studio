# 🛠 Montazhka PRO v3.0

Комплексная CRM-система и Telegram-бот для управления производством наружной рекламы. Объединяет веб-панель для администраторов и мобильный интерфейс (через Telegram) для сотрудников: монтажников, печатников и дизайнеров.

## 🚀 Главные фишки

* **Умное распределение задач:** Разделение заказов на «Общие» (кто успел, тот забрал) и «Личные» (с моментальным push-уведомлением конкретному сотруднику).
* **Разделение по ролям:** Гибкая система допусков (Дизайн, Печать, Монтаж). Каждый видит только свою работу.
* **Глубокая интеграция с Telegram-группой:**
  * Создание заказов прямо из чата по хештегу `#заказ`.
  * Автоматическая пересылка фотоотчетов со сданных объектов в общую группу.
  * Утренняя сводка (будильник) по горящим дедлайнам каждый день ровно в 08:00.
* **Геймификация:** Встроенный рейтинг (Топ сотрудников по закрытым задачам) для мотивации команды.
* **Быстрая админка:** Вход по PIN-коду, загрузка фото через буфер обмена (Ctrl+V), массовые рассылки объявлений всему персоналу.

## 💻 Технологический стек

* **Frontend / Web Admin:** Next.js (React), Tailwind CSS, Lucide Icons.
* **Backend / Database:** Supabase (PostgreSQL, Storage, Realtime).
* **Telegram Bot:** Python 3, aiogram 3.x, FSM (Машина состояний).
* **Хостинг:** Vercel (Сайт) / Любой VPS или облако (Бот).

## 🗄 Структура Базы Данных (Supabase)

Проект использует две основные таблицы и одно хранилище (Storage):

1. **`profiles`** (Сотрудники)
   * ID, ФИО, PIN-код, Роль (admin/installer).
   * Допуски (`can_design`, `can_print`, `can_install`).
   * `telegram_chat_id` (для связи сайта с ботом сотрудника).

2. **`orders`** (Заказы)
   * Название, описание, дедлайн, отдел (`department`).
   * Статус (`new`, `in_progress`, `completed`).
   * Автор (`created_by`) и Исполнитель (`assigned_to`).
   * Фото (эскизы `image_urls` и финальный отчет `report_photo`).

3. **Storage Bucket:** `order-photos` (Папки `previews/` и `reports/`).

## ⚙️ Настройка и запуск

### 1. Переменные окружения (.env)
Создайте файлы `.env` (для бота) и `.env.local` (для сайта) со следующими ключами:

**Для сайта (Next.js):**
```env
NEXT_PUBLIC_SUPABASE_URL=твоя_ссылка_supabase
NEXT_PUBLIC_SUPABASE_ANON_KEY=твой_ключ_supabase
NEXT_PUBLIC_TELEGRAM_BOT_TOKEN=токен_бота_от_botfather
Для бота (Python):

Фрагмент кода
TELEGRAM_BOT_TOKEN=токен_бота_от_botfather
SUPABASE_URL=твоя_ссылка_supabase
SUPABASE_KEY=твой_сервисный_ключ_supabase
2. Запуск Сайта (Админки)
Bash
npm install
npm run dev
Сайт будет доступен по адресу: http://localhost:3000. Для первого входа создайте пользователя с ролью admin напрямую в таблице profiles в Supabase.

3. Запуск Telegram-бота
Убедитесь, что установлен Python 3.9+.

Bash
pip install aiogram supabase python-dotenv
python main.py
4. Настройка Telegram-группы
Добавьте бота в ваш рабочий чат Telegram.

Сделайте бота Администратором группы (чтобы он мог читать сообщения).

Узнайте ID группы (обычно начинается с -100...) и укажите его в main.py и handlers/orders.py в переменной GROUP_CHAT_ID.

Впишите свой личный Telegram ID в ADMIN_IDS в файле handlers/orders.py, чтобы бот принимал заказы через #заказ только от вас.

📱 Как работать с системой
Добавление сотрудников: Зайдите в Админку -> «Команда» -> Создайте профиль. Сотрудник получит PIN-код.

Привязка бота: Сотрудник пишет боту /start, вводит свой PIN-код. Бот связывается с базой, и сотрудник получает свое меню (зависит от выставленных галочек допусков).

Работа с заказами: Админ создает заказ на сайте (или через группу). Если заказ общий — он падает в «Свободные». Монтажник нажимает «Забрать себе», едет на объект, вешает вывеску, жмет «Завершить» и прикрепляет фотоотчет. Фото моментально улетает в рабочий чат.
