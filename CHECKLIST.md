## 🎯 Функциональность в действии

### Сценарий 1: Поиск заказа
1. Пользователь вводит "Монтаж" в поле поиска
2. Компонент фильтрует заказы, где title или description содержит "Монтаж"
3. Результаты обновляются в реальном времени
4. Счетчик показывает "Найдено заказов: X / Y"

### Сценарий 2: Сортировка по дедлайну
1. Пользователь выбирает "По дедлайну" в select
2. Заказы с дедлайном появляются первыми (отсортированы по возрастанию)
3. Заказы без дедлайна в конце
4. Сортировка работает с отфильтрованным списком

### Сценарий 3: Переключение видов
1. Пользователь находится в режиме "Плитки" (Grid)
2. Видит заказы как плитки в сетке (2-4 колонки в зависимости от экрана)
3. Нажимает "Список"
4. Видит компактные строки с основной информацией
5. Может легко переключаться между режимами

### Сценарий 4: Комбинированный поиск и сортировка
1. Пользователь вводит поиск
2. Фильтруется список
3. Выбирает сортировку
4. Отсортированный отфильтрованный список отображается
5. Переключается между видами - все работает корректно
