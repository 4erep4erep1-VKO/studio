## ⚙️ Переменные окружения

### Что добавить в `.env.local`

```env
# Telegram Bot Token (получить у @BotFather)
TELEGRAM_BOT_TOKEN=123456789:ABCDefGhIjKlMnOpQrStUvWxYz...

# ID Telegram группы для уведомлений
# (получить из https://api.telegram.org/botYOUR_TOKEN/getUpdates)
TELEGRAM_GROUP_CHAT_ID=-1001234567890
```

### Как получить эти значения?

1. **Создайте Telegram бота:**
   - Откройте Telegram → найдите @BotFather
   - Напишите `/newbot` и следуйте инструкциям
   - Получите токен

2. **Получите ID группы:**
   - Добавьте бота в группу
   - Откройте: `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
   - Найдите `"chat":{"id":YOUR_ID}`

## 📊 Как работает

### Процесс отправки уведомления

```
1. Пользователь заполняет форму создания заказа
2. Нажимает "Запустить в работу"
3. Данные сохраняются в Supabase
4. ↓
5. Server Action автоматически:
   - Формирует HTML сообщение
   - Отправляет POST запрос к Telegram API
   - Логирует результат
6. ↓
7. В Telegram группе появляется красиво отформатированное сообщение
   с полной информацией о заказе
```

### Примеры сообщений в группе

#### Общий заказ (в группе видят все)
```
🆕 Новый заказ (создан на сайте)

📦 Название: Монтаж кровельного покрытия

📝 Описание: Установка кровельного покрытия на крышу офиса

🏢 Отдел: 🛠 Монтаж
📌 Тип: 🌍 Общий
📅 Дедлайн: 20 мая 2026

📐 Размеры: 50x30 метров
🎨 Материал: Гибкая черепица
🔗 Ссылка на макет: https://example.com/design

⏱ Время создания: 13.05.2026, 10:30:45
```

#### Личный заказ (+ отдельное уведомление исполнителю)
- В группе: появится то же сообщение
- Исполнителю: придет уведомление с сообщением: "Тебе назначили новый объект: Монтаж кровельного покрытия"
